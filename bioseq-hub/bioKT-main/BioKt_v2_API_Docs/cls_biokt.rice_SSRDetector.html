SSRDetector

📄 rice/ · Rice Genomics (biokt.rice) module
MISA-style simple sequence repeat (microsatellite) detector. Finds mono- through hexa-nucleotide repeat motifs.

▶ Code Example
val seq  = DNASequence("ATCGATCGATCG" + "AT".repeat(8) + "GCGCGCGCGCGCGC")
val ssrs = SSRDetector.detect(seq, motifLengths = 1..6)

ssrs.forEach { ssr ->
    println("${ssr.motif}×${ssr.repeats} at ${ssr.start}-${ssr.end} [${ssr.type}]")
}

val stats = SSRDetector.summarise(ssrs)
println("Total SSRs: ${stats["total"]}")
println("By type:    ${stats["by_type"]}")
