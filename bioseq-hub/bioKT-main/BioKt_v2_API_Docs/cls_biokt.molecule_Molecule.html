class

Molecule

📄 Molecule.kt · Molecule module
Molecular graph built by parsing a SMILES string. Provides atom/bond queries, ring detection, and basic property calculation.

Properties 6

Name / TypeDescription
smiles: String Input SMILES string
name: String Molecule name (optional)
id: String Molecule identifier
atoms: List<Atom> All heavy atoms in the graph
bonds: List<Bond> All bonds
rings: List<Ring> SSSR rings detected by DFS

▶ Code Example
val aspirin = Molecule("CC(=O)Oc1ccccc1C(=O)O", name="Aspirin")
println(aspirin.molecularFormula())  // C9H8O4
println(aspirin.exactMass())         // 180.042
println(aspirin.numRings())          // 1
println(aspirin.numAromaticRings())  // 1

val caffeine = Molecule("Cn1cnc2c1c(=O)n(c(=O)n2C)C", name="Caffeine")
println(caffeine.molecularFormula()) // C8H10N4O2
println(caffeine.numRings())         // 2
