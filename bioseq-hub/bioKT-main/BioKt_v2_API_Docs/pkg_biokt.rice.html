Rice Genomics (biokt.rice)

rice/

Rice-specific genomics subpackage. Import with: import biokt.rice.* Covers VCF variant analysis, GFF3 genome annotation, SSR/cis-element/TE/R-gene analysis, RNA-seq normalisation and DE, and haplotype block/selection sweep analysis for Oryza sativa research.
