GPTClient

📄 GPTClient.kt · GPT Client module
REST API client for LLM providers. Built-in biological interpretation methods for DNA, protein, and drug molecules. Create via factory methods.

Properties 5

Name / TypeDescription
provider: LLMProvider OPENAI | ANTHROPIC | GOOGLE | OLLAMA
model: String Model ID string (e.g. gpt-4o, claude-sonnet-4-5)
maxTokens: Int Maximum response length (default 1200)
temperature: Double 0.0 = deterministic, 1.0 = creative (default 0.3)
systemPrompt: String Bioinformatics expert system prompt (can be overridden)

▶ Code Example
// OpenAI
val gpt = GPTClient.openai(apiKey = System.getenv("OPENAI_API_KEY"))

// Anthropic Claude
val claude = GPTClient.anthropic(apiKey = System.getenv("ANTHROPIC_API_KEY"))

// Local Ollama (free, offline, no key needed)
val local = GPTClient.ollama(model = "llama3")

// DNA interpretation with ML predictions
val dna    = DNASequence("ATGGCCATTGTAATGGGCCGCTGA")
val mlPred = SequenceMLPredictor.fullAnalysis(dna)
val resp   = gpt.interpretDNA(dna, mlPred)

if (!resp.isError()) {
    println(resp.text)
    println("Tokens: ${resp.totalTokens}")
}

// Drug interpretation
val aspirin = Molecule("CC(=O)Oc1ccccc1C(=O)O", name="Aspirin")
val drugML  = DrugMLPredictor.fullAnalysis(aspirin)
println(claude.interpretDrug(aspirin, drugML).text)

// Extension functions
val interp = dna.interpretWith(gpt, mlPred)
println(interp.text)
