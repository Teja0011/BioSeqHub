SequenceMLPredictor

📄 MLPredictor.kt · ML Predictor module
DNA sequence classification: coding vs non-coding, promoter detection, splice site identification.

Method Summary 4

MethodReturnsDescription
predictCoding(seq) MLPrediction Coding vs non-coding — Fickett-inspired 7-feature NaiveBayes (GC, complexity, codon bias, ORF density)
predictPromoter(seq) MLPrediction Promoter vs non-promoter — TATA-box, CpG density, GC-box, CAAT-box features
predictSpliceSite(seq, position) MLPrediction donor / acceptor / non-splice — GT-AG score, polypyrimidine tract, branch point signal
fullAnalysis(seq) Map<String,MLPrediction> All three classifiers in one call: coding, promoter, splice_site

▶ Code Example
val dna = DNASequence("ATGGCCATTGTAATGGGCCGCTGAAAGGGTGCCCGATAG")

// Single prediction
val coding = SequenceMLPredictor.predictCoding(dna)
println(coding.label)         // "coding"
println(coding.confidence)    // 0.83
println(coding.summary())

// All three at once
val all = SequenceMLPredictor.fullAnalysis(dna)
all.forEach { (task, pred) ->
    println("$task: ${pred.label} (${pred.confidence})")
}
