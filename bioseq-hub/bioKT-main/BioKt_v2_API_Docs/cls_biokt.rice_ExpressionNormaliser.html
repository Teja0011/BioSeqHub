ExpressionNormaliser

📄 rice/ · Rice Genomics (biokt.rice) module
RNA-seq count normalisation: TPM, FPKM, RPKM, DESeq2 size-factor, and quantile normalisation.

Method Summary 5

MethodReturnsDescription

▶ Code Example
// Raw count matrix [genes × samples]
val rawCounts: Array<DoubleArray> = loadCountMatrix()
val geneLengths: DoubleArray = loadGeneLengths()

val tpm  = ExpressionNormaliser.toTPM(rawCounts, geneLengths)
val fpkm = ExpressionNormaliser.toFPKM(rawCounts, geneLengths)

// DESeq2-style normalisation for DE analysis
val (normCounts, sizeFactors) = ExpressionNormaliser.sizeFactorNormalise(rawCounts)
println("Size factors: ${sizeFactors.joinToString { "%.3f".format(it) }}")
